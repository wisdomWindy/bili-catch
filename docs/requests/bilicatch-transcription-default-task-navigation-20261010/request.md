# 请求：修复转写默认语言与任务页切换延迟

## 请求标识

`bilicatch-transcription-default-task-navigation-20261010`

## 来源链接

2026-10-10 当前 Codex 会话中的直接用户缺陷报告，附带音频转文本页面截图。

## 业务摘要

将音频转文本页面的默认语言由“自动检测”改为“简体中文”，并让侧边栏点击“任务列表”后立即呈现任务页面，任务数据在页面出现后异步加载。

## 目标陈述

用户进入音频转文本页面时，在未显式修改默认转写语言的情况下看到“简体中文”；用户点击任务列表菜单后，路由和页面标题立即切换，下载任务与转写任务的订阅和快照读取不阻塞首次绘制。

## 初始完成信号

- 设置默认值及旧版缺省字段迁移结果为 `zh`。
- 转写表单在设置尚未加载或设置缺省时以 `zh` 初始化。
- 任务页先完成 DOM 渲染，再启动任务订阅和列表加载。
- 定向前端、Rust 测试与构建通过。

## 触发条件

1. 启动使用旧版 `schemaVersion: 1` 设置文件或全新设置的应用，进入音频转文本页面。
2. 从其他页面点击侧边栏“任务列表”。

## 初始上下文来源

- 用户缺陷描述与截图。
- 本机 `com.bilicatch.app/settings.json`，其中 `schemaVersion` 为 1 且无 `defaultTranscriptionLanguage` 字段。
- `SettingsDefaults::values`、`migrate_document`、`TranscribePage.vue`。
- `TasksPage.vue`、下载任务和转写任务事件订阅实现。

## 人工交接点

按仓库默认隐式审批完成 spec 与 plan；实现、验证和评审结论均写入本请求工作区。

设置默认值和兼容迁移、转写页表单缺省值、任务页首次挂载调度及对应测试。保持语言下拉可选项、用户显式设置、任务数据契约和路由结构不变。

## 参与服务或模块

`services::settings`、`TranscribePage`、`TasksPage`、任务管理 store、转写 store。

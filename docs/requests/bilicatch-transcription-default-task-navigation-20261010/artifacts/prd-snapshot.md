# PRD 快照

## 用户需求

1. 音频转文本页面语言选项默认简体中文。
2. 点击任务列表菜单立即切换到任务列表页面，任务数据在切页后加载。

## 验收标准

- AC-01：全新设置文档的 `defaultTranscriptionLanguage` 为 `zh`。
- AC-02：旧版设置文档缺少该字段时，迁移结果为 `zh`；已有合法显式值保持不变。
- AC-03：转写页面表单的前端缺省语言为 `zh`，设置加载后继续以设置值为准。
- AC-04：任务页组件挂载后首先可渲染标题与加载态，任务事件订阅及列表读取在后续调度周期才启动。
- AC-05：页面卸载前若初始化尚未开始，应取消待执行调度，不产生离页后的订阅。

## 非目标

- 不移除“自动检测”语言选项。
- 不强制覆盖用户已显式保存的合法语言设置。
- 不改变任务列表的数据契约、排序、筛选和操作行为。
- 不进行页面视觉重设计。

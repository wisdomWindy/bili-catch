## 业务摘要

从零开发 BiliCatch V1.0：一款基于 Tauri v2、Vue 3 和 TypeScript 的跨平台 B 站视频/音频下载桌面应用。产品覆盖链接解析、音频下载、视频下载与合并、任务队列、扫码登录、设置持久化、系统托盘/通知/更新以及安装包交付。

## 目标陈述

交付一个可运行、可测试、可打包的 BiliCatch V1.0 工程，使用户能够在匿名或登录状态下解析其有权访问的 B 站内容，选择媒体参数，管理下载任务，并通过桌面系统能力完成文件选择、通知、托盘与更新操作。

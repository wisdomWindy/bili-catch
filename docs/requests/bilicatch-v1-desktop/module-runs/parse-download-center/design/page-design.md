# 页面设计：解析与下载中心

## 交付单元标识

`parse-download-center`

## 页面目标

把 `/download` 从基础占位页升级为单页解析工作台：用户输入任一支持的 B 站链接或 BV/AV ID，清楚经历校验、解析、选择分 P 与媒体参数、生成下载任务草稿的完整流程。

## 信息结构

页面纵向由五个稳定区块组成：链接输入 -> 状态/错误 -> 视频身份 -> 分 P 选择 -> 下载配置与操作。解析前仅显示输入区和简短说明；解析后结果在同页下方出现，不使用弹窗或新路由。

### 输入区

- 单行 URL/ID 输入，占主行剩余宽度；右侧 88px“解析”主按钮。
- 支持标准 URL、移动 URL、b23 短链、BV/AV ID、带 `p` 参数链接。
- 空白输入禁用按钮；Enter 与按钮触发一致。
- 输入区域可接收文本拖拽；合法剪贴板文本粘贴后自动解析。普通手工键入不自动请求。
- 解析中输入仍可见但不可重复提交，按钮显示 spinner 与“解析中”。

### 状态与错误

- 校验错误显示在输入下方并把焦点留在输入，不清空用户内容。
- 网络、视频不可用、地区限制、登录要求和签名失败使用内联 alert；需要登录时提供明确“前往登录”按钮。
- 重试保持输入；清空彻底回到 initial。

### 视频身份区

- 桌面为 240x135 16:9 封面 + 右侧标题/UP 主/时长/视频标识。
- 封面加载失败显示固定比例占位，不推动布局。
- 900px 以下堆叠，封面最大 320px；正文不覆盖或横向溢出。

### 分 P 区

- 单 P 不显示批量工具，只显示当前分 P 摘要。
- 多 P 显示“已选 n/m”、全选、反选，以及可滚动 checkbox 列表；默认选中 URL 指定 P，否则第一 P。
- 行包含 P 序号、标题、时长；点击整行切换，checkbox 有可访问名称。
- 0 项选中时入队按钮禁用并显示原因。

### 下载配置区

- 下载类型为三项 radio：视频+音频、仅视频、仅音频。
- 视频模式显示清晰度与编码；音频模式显示格式与码率。条件切换不保留非法组合。
- 选项只来自解析结果能力，不展示实际不可用的清晰度；匿名状态对 1080P+ 显示登录提示而不是伪可选。
- 保存目录显示为只读路径和“更改”按钮；本模块使用设置默认值/安全 fallback，系统目录选择接 system-release。

### 操作区

- 左侧“清空”为次按钮，右侧“添加到下载队列”为主按钮。
- 入队条件：解析成功、至少一个分 P、当前模式所有必要参数有效。
- 成功后通知“已添加到下载队列”并跳转 `/tasks`；会话级草稿由下游任务模块消费。

## 状态矩阵

| 状态 | 输入 | 结果 | 主操作 |
| --- | --- | --- | --- |
| initial | 可编辑 | 隐藏 | 解析禁用 |
| invalid | 保留并聚焦 | 隐藏 | 可修正后重试 |
| parsing | 锁定 | skeleton，稳定高度 | 防重复提交 |
| success | 可清空/重新解析 | 完整可配置 | 满足规则后入队 |
| failed | 保留 | inline alert | 重试/登录/清空 |
| enqueueing | 锁定配置 | 保留 | spinner，防重复入队 |

## 视觉与响应式

- 复用基础模块语义 token、AppShell 与 24/16px 内容 padding，不新增第二套主题规则。
- 表单控件 36-40px，区块以标题、间距和细边框分组；不把每个字段包装成卡片。
- `>=1100px` 参数为 2-3 列；`860-1099px` 两列；窄容错单列。
- 分 P 列表最大约 320px 高独立滚动，页面操作区不随长列表消失。
- loading/error/empty 使用稳定最小高度，避免页面跳动。

## 可访问性

- 每个 input/select/radio/checkbox 均有真实 label；错误通过 `aria-describedby` 关联。
- 解析状态用 `aria-live=polite`，失败用 `role=alert`；按钮 disabled 原因同时可见。
- 拖拽不是唯一入口；所有功能可键盘完成。
- 封面 alt 使用视频标题；装饰图标隐藏。

## 开放 UI 问题

- 最终目录选择器由 system-release 接管，本模块只显示路径与 disabled/说明态。
- 任务页在下一模块实现；本模块成功跳转后只保证草稿已进入稳定边界，不提前设计任务行。

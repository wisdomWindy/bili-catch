# 设置管理：澄清与决策

## CL-SET-01 语言默认值

### 问题

PRD 列出简体中文与 English，但默认值表未单列语言默认值。

### 答案

PRD 6.3 说明 V1.0 内置简体中文并预留英文结构，现有应用默认也是 `zh-CN`。

### 最终决策

V1 持久设置默认 `locale="zh-CN"`；English 是完整可切换选项。

### 影响规格区域

字段合同、启动恢复、国际化、SET-AC-06/16。

## CL-SET-02 视频清晰度存储值

### 问题

“默认 1080P”应存展示文本、语义枚举还是解析服务 quality id？

### 答案

下载中心已经以 B 站 quality id 选择媒体；存稳定字符串 id 可直接与解析结果匹配，展示文本继续由 i18n/options 提供。

### 最终决策

使用 V1 `VideoQualityId`：`16/32/64/80/112/120/125/127`，默认 `80`。解析结果不含该 id 或需登录时退到首个可用值。

### 影响规格区域

共享媒体 contract、字段合同、下载设置消费、SET-AC-05/11。

## CL-SET-03 并发设置生效时机

### 问题

用户降低最大并发或修改连接数时，是否调整已运行任务？

### 答案

强制缩减现有执行会引入暂停/取消副作用，PRD 只要求可配置调度范围。

### 最终决策

设置只影响后续任务认领/attempt；已运行任务不终止。活动数降到新上限前不再认领，连接数只在新 attempt 创建时读取。

### 影响规格区域

任务调度消费、边界情况、SET-AC-12。

## CL-SET-04 目录文本语义

### 问题

路径输入框是否允许手动输入，以及是否 trim/展开 `~`？

### 答案

PRD 指定目录选择器，系统 dialog 已返回平台路径；手动文本输入会增加跨平台歧义。

### 最终决策

路径输入只读。前端不 trim、不展开、不拼接；Rust 接受 dialog 返回的绝对且存在目录。默认下载目录和临时目录由 Rust 从安装目录解析，并创建 download 与 temp 子目录。

### 影响规格区域

目录流程、字段合同、边界情况、SET-AC-03。

## CL-SET-05 滑块键盘提交

### 问题

PRD 只说明“释放后保存”，键盘没有指针释放事件。

### 答案

键盘用户需要等价且不会每一刻度写盘的提交边界。

### 最终决策

指针/触摸使用 change/释放提交；键盘修改实时预览，在 change 或失焦提交一次最终值。单字段 drain 合并保存期间的新值。

### 影响规格区域

修改流程、字段合同、无障碍、SET-AC-04/08。

## CL-SET-06 更新与许可配置缺失

### 问题

当前模块要求检查更新和许可入口，但 PRD 未提供 update endpoint、公钥或许可 URL，且这些属于后续 `system-release`。

### 答案

猜测或硬编码目标会制造不可信行为；页面交互和 port 可先稳定。

### 最终决策

当前模块实现完整 UI 状态与 `ReleaseActionsPort`，production 使用 deferred adapter 返回 `UPDATE_NOT_CONFIGURED` / `LICENSES_NOT_CONFIGURED`。`system-release` 替换 adapter。不得误报“已最新”或打开空 URL。

### 影响规格区域

范围外、关于区、API contract、SET-AC-13/14。

## CL-SET-07 plugin-store 事务语义

### 问题

plugin-store `set` 先更新 cache，若显式 `save` 失败，如何保证失败 candidate 不在未来落盘？

### 答案

当前 Tauri v2 Rust API 的 `get/set/save` 同步，`StoreBuilder` 支持 `disable_auto_save()`。

### 最终决策

Rust adapter 关闭 auto-save，保存前缓存旧 value；执行 `set(candidate) -> save()`，失败立即恢复旧 cache。manager 只在 adapter 成功后提交自身内存和 revision。

### 影响规格区域

Side Effect、StorePort、边界情况、SET-AC-09/10。

## CL-SET-08 损坏或非法持久值

### 问题

旧文档缺字段、含非法字段或整体不可读取时如何恢复？

### 答案

字段级兼容可通过 migration 安全修复；整体 I/O/反序列化失败时覆盖原文件会丢失恢复证据。

### 最终决策

缺失/未知/字段级非法值迁移为完整 V1 并写回；整体无法读取时返回 load error 且不覆盖文件。未来 schema 必须用显式迁移函数。

### 影响规格区域

启动恢复、迁移策略、边界情况、SET-AC-09。

## CL-SET-09 下载页现有选择与设置更新

### 问题

设置在下载页已打开且用户已手动选择参数时发生变化，是否立即覆盖当前选择？

### 答案

覆盖当前选择会破坏用户正在进行的任务配置；设置应作为默认，而不是强制策略。

### 最终决策

已确认设置只影响尚无当前用户覆盖的输出目录和后续解析结果；当前手动选择保持。清空后下一次解析使用最新默认。

### 影响规格区域

下载设置消费、边界情况、SET-AC-11。

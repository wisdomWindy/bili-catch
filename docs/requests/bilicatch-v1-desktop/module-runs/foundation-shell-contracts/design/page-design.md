# 页面设计：应用基础、壳层与共享契约

## 交付单元标识

`foundation-shell-contracts`

## 页面目标

建立可承载下载中心、任务列表、登录和设置的桌面工作台壳层。用户在任意业务页都能快速判断当前位置、登录状态，并以最少移动切换主要工作区。

## 目标用户与场景

- 学习者和归档用户：持续添加链接并查看队列，需要稳定、低干扰的工具界面。
- 创作者：频繁切换下载参数和目录，需要较高信息密度与明确状态。
- 桌面多任务场景：窗口可能从紧凑尺寸到宽屏全屏，导航与内容不能重叠或跳动。

## 布局结构

应用使用三段式固定框架：

```text
+----------------+--------------------------------------------------+
| Brand / mark   | Top bar: back, page title, auth, settings        |
|----------------+--------------------------------------------------|
| Primary nav    |                                                  |
| Download       | Routed content                                   |
| Tasks          | max readable width, left aligned                 |
| Settings       |                                                  |
|                |                                                  |
|----------------|                                                  |
| Version/status |                                                  |
+----------------+--------------------------------------------------+
```

- 桌面侧栏宽 208px，顶栏高 56px；内容区占剩余空间。
- 内容区内部最大宽度 1180px，居中但内容始终左对齐；任务表等高密度页面可申请全宽。
- 窗口最小建议尺寸 860x600，默认约 1180x760。
- 顶栏固定在内容区顶部，侧栏贯穿全高；业务内容独立滚动。

## 视觉层级

1. 应用品牌 `BiliCatch`：侧栏顶部第一视线，图形标记与文字并列，不使用营销式大标题。
2. 当前页面：顶栏页面标题与侧栏选中态同步。
3. 主操作：业务页内使用实心强调按钮，壳层不放置抢占注意力的 CTA。
4. 状态入口：登录状态以头像/用户图标 + 简短状态呈现；设置使用齿轮图标按钮。
5. 辅助状态：版本和本地/连接状态位于侧栏底部，低对比度展示。

## 区块拆分

### 品牌区

- 32px 图标占位、产品名、可选紧凑版只保留图标。
- 点击品牌回到 `/download`。

### 主导航

- 三项：下载中心（Download）、任务列表（ListTodo）、设置（Settings）。
- 每项使用 Lucide 图标 + 文本；44px 稳定高度；当前项有 3px 左侧强调条和浅色背景。
- 任务项可在后续模块加入活动任务数量徽标，预留 28px 尾部区域，避免布局变化。

### 顶栏

- 左侧返回按钮仅在存在可返回历史时启用，否则保持位置并禁用，防止标题横移。
- 中间为当前页标题，不重复放置大段说明。
- 右侧依次为登录状态入口和设置图标；所有纯图标按钮带 tooltip 与 `aria-label`。

### 路由内容区

- 页面容器统一使用 24px 桌面内边距、16px 紧凑窗口内边距。
- 页面 section 使用无框的分区和细分隔线；卡片只用于解析结果、单个任务/重复项或真正的工具框。
- 页面加载、空、错误区域占据稳定最小高度，状态切换不推动壳层。

### 全局反馈层

- 顶部右侧消息/通知堆叠，最多同时 3 条。
- 阻断性确认使用对话框；普通成功和错误使用可关闭通知。
- 后端不可用时展示紧凑横幅，不覆盖导航。

## 样式方向

- 字体：系统 UI 字体栈；正文 14px，页面标题 20px/600，section 标题 16px/600；不随视口缩放字号。
- 圆角：输入和按钮 6px，卡片最大 8px；不使用胶囊式大按钮。
- 间距：4px 基础单位，常用 8/12/16/24px。
- 亮色：背景 `#F7F8FA`、表面 `#FFFFFF`、主文字 `#202124`、次文字 `#646A73`、边框 `#D9DDE3`。
- 暗色：背景 `#161719`、表面 `#202225`、主文字 `#F2F3F5`、次文字 `#A8ADB5`、边框 `#363A40`。
- 品牌/关键操作：`#E84A72`；hover 使用更深的实色，不使用渐变。
- 信息：`#2878C8`；成功：`#16856B`；警告：`#B56A14`；危险：`#C83F49`。
- 焦点环至少 2px，颜色与背景保持可见对比；不能只用颜色表达任务或登录状态。
- 图标统一使用 Lucide，不手绘 SVG；熟悉工具命令优先图标按钮。

## 交互骨架

- 路由切换立即更新侧栏选中态和标题；内容区滚动位置按页面独立管理。
- 返回按钮调用路由历史；直接打开的首屏保持禁用。
- 点击登录状态进入 `/login`；设置图标和侧栏设置都进入 `/settings`。
- 键盘 Tab 顺序遵循侧栏 -> 顶栏 -> 页面内容；Enter/Space 可触发导航。
- 主题在切换后直接更新根节点属性，避免整页闪白；首次渲染读取系统主题和持久设置。
- 语言切换后所有壳层文本即时变化；布局为中文和英文较长标签预留空间。
- 路由页面发生未处理异常时，在内容区展示恢复入口，壳层导航继续可用。

## 响应式行为

- `>= 1100px`：208px 完整侧栏，内容最大宽度 1180px。
- `860-1099px`：侧栏缩为 72px，只显示图标；tooltip 提供名称，品牌区只保留图标。
- `< 860px`：作为开发预览/极窄窗口容错，侧栏变为 60px 图标轨道，顶栏隐藏独立设置入口以避免与登录状态冲突；设置仍可从侧栏访问。
- 导航宽度切换不使用字体缩放；内容通过明确 grid track 和 `min-width: 0` 防止溢出。
- 最长英文标签允许在 tooltip 中完整显示，侧栏紧凑态不挤压文字。

## 状态规格

| 状态 | 壳层表现 |
| --- | --- |
| 初始化 | 内容区固定高度 skeleton，导航立即可见 |
| 匿名 | 顶栏显示用户图标和“未登录”，可点击 |
| 已登录 | 显示头像或稳定占位、昵称和下拉入口 |
| 后端不可达 | 内容区上方横幅，业务命令禁用，导航和设置可用 |
| 路由错误 | 内容区显示错误标题、返回下载中心按钮 |
| 暗色 | 通过语义 token 全量切换，不反转媒体图片 |

## 设计风险

- Tauri 窗口过窄时导航与顶栏可能争夺空间；通过固定轨道和隐藏冗余入口控制。
- Naive UI 默认主题可能使页面呈现单一蓝色或圆角过大；必须覆盖语义 token 并限制卡片/按钮圆角。
- 后续任务页需要更宽内容；路由容器需支持 `content--wide` 变体，不能嵌套卡片制造空间损失。
- macOS 标题栏/traffic lights 与自定义顶栏存在冲突风险；首版使用系统标题栏，应用顶栏只承担内容导航。

## 开放 UI 问题

- 应用图标资源尚未提供；实现阶段使用可替换的文字/简单占位资源，不宣称最终品牌图标。
- 用户头像在匿名或外部 URL 失败时使用首字/用户图标占位。
- 系统原生标题栏的最终风格由平台打包验证决定，不在本模块定制无边框窗口。

# 模块：设置管理

## 模块标识
`settings`

## 来源快照

- `/settings` 分下载、外观、系统、关于四组。
- 下载：下载目录、临时目录、最大并发 1-10 默认 3、连接数 1-32 默认 8、默认 1080P、默认 MP3。
- 外观：亮/暗/跟随系统；简体中文/English。
- 系统：完成通知默认开；关闭窗口默认最小化托盘；自动更新默认开。
- 关于：版本、检查更新、开源许可。
- 全部即时保存；目录用系统选择器；滑块释放保存；主题/语言即时生效。

## Markdown 归一化快照
原表格完整保留为分组字段清单，并把默认值、范围、控件与保存时机合并到同一字段定义。

## 来源追踪
`biliCatch_PRD.md` 模块六（约 479-534 行）、6.3、6.4。

## 业务意图
让用户配置下载、外观和系统行为，并在重启后可靠恢复。

## 用户可见范围
完整设置页、即时保存反馈、主题/语言切换、目录选择、更新检查和许可入口。

## 表单、表格、展示与交互
两个路径选择、两个滑块、五个选择器、两个开关、版本文本、更新按钮和许可链接。

## 工作流与状态规则
加载默认/持久值 -> 编辑 -> 即时 UI 应用（主题/语言）-> 持久化；失败时回退或显示错误。范围在边界层再次校验。

## 依赖与受影响邻居
依赖基础主题/i18n/store；影响任务调度、媒体默认值、通知、窗口和更新。

## 页面设计路由判定
需要：分组式桌面设置布局和紧凑控件对齐。

## 架构设计路由判定
需要：版本化设置模型、默认值、迁移、即时副作用与 Tauri store adapter。

## 下游规格义务
不得遗漏任何字段、范围、枚举、默认值、控件类型和保存时机。

## 开放问题
开源许可目标地址与更新端点由系统发布模块配置。

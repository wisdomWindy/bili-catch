# 模块：视频下载与音视频合并

## 模块标识
`video-download`

## 来源快照

- 支持视频+音频与仅视频；根据源展示 AVC/HEVC/AV1 和清晰度。
- 匿名最高 480P；登录按权限最高 8K/HDR。
- 视频+音频并行下载 DASH 两轨，再由 FFmpeg 无损封装；仅视频不合并。
- 进度通过任务系统推送；下载中断自动重试；合并失败为 E008；成功清理临时文件。

## Markdown 归一化快照
原流程归一为能力选择、双轨下载、聚合进度、合并和终态五部分；条件分支保持不变。

## 来源追踪
`biliCatch_PRD.md` 模块三（约 295-339 行）、5.1、7.3。

## 业务意图
可靠下载 B 站 DASH 视频并按用户选择输出仅视频或完整音视频文件。

## 用户可见范围
复用下载中心视频参数和任务页进度/操作，无新增路由。

## 表单、表格、展示与交互
清晰度、编码、下载类型、分 P 和路径由既有页面提供。

## 工作流与状态规则
排队 -> 获取流 -> 单/双轨并行下载 -> 可选合并 -> 完成；取消清理所有临时轨；失败可重试。

## 依赖与受影响邻居
依赖解析、任务、认证、设置、下载器和 FFmpeg；影响通知与文件打开。

## 页面设计路由判定
不需要独立页面设计。

## 架构设计路由判定
需要：分片并发、聚合进度、取消、断点续传和 FFmpeg sidecar。

## 下游规格义务
保留模式、权限、编码、并行下载、无损封装、清理、重试与 E007-E009。

## 开放问题
HDR/8K 的具体 codec/container 组合由源能力 adapter 决定。

# 模块：解析与下载中心

## 模块标识
`parse-download-center`

## 来源快照

- 支持标准/移动 URL、短链、BV/AV ID、指定分 P。
- `/download` 展示 URL 输入、解析按钮、封面、标题、UP 主、时长、分 P、下载类型、视频或音频参数、保存目录、入队与清空。
- 空输入禁用；有效剪贴板/拖拽可自动解析；加载后渲染结果。
- 多 P 默认第一项，支持全选/反选；模式切换控制参数显示；入队后提示并跳转任务页。
- WBI 缓存约 12 小时，失败刷新后重试一次；匿名 480P 上限；错误按 E001-E006 等映射。

## Markdown 归一化快照
原始页面图以代码块表示，现线性化为“输入区 -> 结果身份区 -> 分 P 区 -> 下载模式与参数区 -> 保存位置 -> 主操作区”，字段和触发结果不变。

## 来源追踪
`biliCatch_PRD.md` 模块一（约 158-243 行）、3.2、4.0、5.1。

## 业务意图
把各种 B 站输入规范化为稳定视频与媒体能力结果，并收集创建下载任务所需参数。

## 用户可见范围
完整 `/download` 页面及解析、选择、清空、入队、跳转、加载和错误反馈。

## 表单、表格、展示与交互
- URL 输入和解析按钮。
- 视频身份展示：封面、标题、UP 主、时长。
- 分 P 多选：默认第一项、全选、反选。
- 下载类型单选；清晰度/编码或格式/码率条件显示。
- 保存目录展示与更改；加入队列与清空。

## 工作流与状态规则
初始 -> 校验 -> 解析中 -> 成功/失败；成功状态可选参数并入队。清空返回初始。相同输入结果可缓存。需要登录时引导 `/login`。

## 依赖与受影响邻居
依赖基础契约；向任务、认证、设置、音频和视频模块输出解析结果与创建任务输入。

## 页面设计路由判定
需要：同页信息较多且具有条件显示、加载/错误/空状态。

## 架构设计路由判定
需要：需要 URL 规范化、外部 API adapter、缓存、DTO 和页面状态组织。

## 下游规格义务
保留五类输入、全部字段、按钮禁用、自动解析、多 P、模式条件显示、WBI 重试、权限提示、入队跳转与错误映射。

## 开放问题
外部 API 精确字段待 adapter 夹具固定。

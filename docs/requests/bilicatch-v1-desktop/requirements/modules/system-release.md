# 模块：系统集成与发布

## 模块标识
`system-release`

## 来源快照

- 托盘：显示主窗口、暂停所有、退出；活动任务时退出确认。
- 通知：下载完成、失败、更新可用。
- 文件对话框与打开位置；窗口位置/大小记忆；关闭行为；链接拖拽。
- updater 启动检查，签名验证，提示安装；FFmpeg 通过 `externalBin` 内置并随更新交付。
- 目标产物覆盖 Windows NSIS/MSI、macOS DMG/App、Linux deb/rpm/AppImage、`latest.json` 与 `.sig`；版本号一致。

## Markdown 归一化快照
原系统表、平台产物表、配置样例和检查清单归并为运行时系统能力、构建配置、发布输入、目标产物和验收清单。

## 来源追踪
`biliCatch_PRD.md` 模块七（约 535-562 行）、6.4、7.1-7.7、8。

## 业务意图
把已完成的业务能力可靠接入桌面操作系统，并形成可发布构建配置。

## 用户可见范围
托盘菜单、系统通知、目录/文件操作、窗口行为、拖拽解析、更新提示。

## 表单、表格、展示与交互
无新页面；消费设置页更新/关闭行为和各业务页状态。

## 工作流与状态规则
关闭按配置最小化或退出；活动任务退出确认；更新检查 -> 无更新/有更新/失败 -> 用户确认安装；通知受设置开关约束。

## 依赖与受影响邻居
依赖全部前序模块；外部依赖 FFmpeg 二进制、图标、Release 仓库、签名和公证材料。

## 页面设计路由判定
不需要独立页面设计，使用系统菜单、对话框和已有设置入口。

## 架构设计路由判定
需要：Tauri plugin 权限、平台适配、配置注入、sidecar 和发布流水线边界。

## 下游规格义务
保留全部菜单项、通知触发、确认规则、产物类型、命名、版本一致、签名、公证和 FFmpeg 检查项。

## 开放问题
真实外部材料未提供，验证必须准确标为待发布环境补齐。

# 模块：音频独立下载

## 模块标识
`audio-download`

## 来源快照

- 仅音频支持 MP3 128K/192K/320K、M4A 原始码率、FLAC 无损。
- FLAC 需要登录且源支持；匿名音频最高 64K，登录最高 192K + HiRes（与输出选项按源能力约束）。
- 流程：获取音频流 -> 下载临时文件 -> FFmpeg 转换（适用时）-> 写入标题/UP 主/封面元数据 -> 完成 -> 删除临时文件。
- M4A 保留原始音质；失败可重试并映射统一错误。

## 业务意图
在不下载视频轨的情况下输出可用且带元数据的音频文件。

## 用户可见范围
复用下载中心音频参数；任务页展示下载/转换进度与失败。

## 表单、表格、展示与交互
无新页面；消费格式、码率、分 P、路径和任务操作。

## 工作流与状态规则
排队 -> 获取流 -> 下载 -> 可选转换 -> 元数据 -> 完成；取消清临时文件，失败保留重试参数。

## 依赖与受影响邻居
依赖解析、任务、认证、设置和 FFmpeg 命令边界；影响通知与输出文件。

## 页面设计路由判定
不需要独立页面设计，沿用已批准下载中心与任务页。

## 架构设计路由判定
需要：下载器 trait、FFmpeg 参数、临时文件和元数据写入边界。

## 下游规格义务
固定能力矩阵、权限校验、阶段进度、清理、重试、E007/E008/E009。

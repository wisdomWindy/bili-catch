- 请求标识：`bilicatch-task-actions-layout-fix-20260913`

- 目标：修复任务列表响应式布局，使各状态的操作按钮在支持的窗口宽度内均位于列表边界内。
- 初始完成信号：可复现宽度下所有 `.task-row__actions` 控件的边界不超过对应 `.task-list`，现有任务操作行为不变。

- 参与模块：`src/features/task-management`；不涉及后端、IPC 或任务状态规则。

## 用户意图合同

- stated request：任务列表的操作列中的按钮显示在表格外面，调整样式，让操作列的按钮显示在列表范围内。
- practical goal：任何任务状态下，操作按钮都能在任务列表中完整显示和操作。

# 页面设计：统一选集界面

## 交付单元

`episode-selection-ui`（4 / 4）。上游：需求分析 H2/H3/H4、模块 1–3 契约、既有下载中心页面规格。

## 用户旅程

角色：已登录或匿名用户。入口：下载中心解析成功后的选集区。
意图：确认“这条链接包含哪些集/分 P”，选出要下载的单元，进入任务。
主决策：选哪几集；主行动：勾选 → 加入队列；完成信号：已选计数与任务草稿数量一致。
恢复路径：清空选择 / 重新解析 / 从任务页返回。

## 信息架构

解析成功后的固定纵向顺序保持不变：输入 → 状态 → 视频身份 → 选集 → 下载设置 → 操作。
选集区内部：

1. 标题行：`选择分 P`（沿用既有文案）+ 已选 n/m + 全选/反选。
2. 单元列表：
   - 单集（`partCount = 1`）：一行，标签 `EP{n}`（合集/番剧）或 `P{page}`（普通视频），后接标题与时长。
   - 多 P 集（`partCount > 1` 且所属为合集/季）：一行集头 `EP{n}` + 子行 `P{page}`。
   - 普通多 P 视频：保持现状，平铺 `P1..Pn`，不出现集头。
3. 不可下载单元：置灰、禁用复选框、行尾原因标签。

## 视觉层级

- 集头与单元行使用同一列表容器，集头略强（字重/背景），子行缩进。
- 主行动仍是“加入队列”，选集为次要操作。
- 不可下载行降低对比度但不隐藏，原因用文本而非仅颜色区分。
- 已选计数为主信息，靠近标题右侧。

## 交互与反馈

- 勾选/取消：立即更新计数与入队可用性。
- 集头勾选：全选/取消其全部可下载子单元；部分选中时集头显示半选态（`indeterminate`）。
- 全选/反选：只作用于可下载叶子单元；不可下载单元不参与。
- 不可下载行：`disabled`，点击无反馈（不是错误弹窗）。
- 默认选中：`requestedCid` → `requestedPage` → 首个可下载 → 首个（模块 2 已实现）。
- 空能力（选项为空）：下载设置区显示“暂无可用选项”，入队禁用，选集仍可浏览。

## 反馈状态

| 状态 | 表现 |
| --- | --- |
| loading | 沿用现有解析中骨架/提示，不新增 |
| 成功 | 列表 + 计数 |
| 部分不可下载 | 混合行，置灰 + 原因 |
| 全部不可下载 | 列表可见、计数 0、入队禁用 |
| 单元标题为空 | 回退 `EP{n}` / `P{n}` |
| 时长 0 | 不显示时长 |
| BV 为空（季级入口） | 身份区隐藏 BV 行 |

## 响应式与可访问性

- 列表最大高度与滚动沿用既有（约 320px），窄宽度下标签不换行、标题截断。
- 复选框使用原生 `input[type=checkbox]`；集头使用 `aria-checked="mixed"` 需通过 `indeterminate` 属性表达。
- 禁用行使用 `disabled`，原因通过 `aria-describedby` 关联文本。
- 焦点顺序：标题操作按钮 → 列表自上而下。

## UX 风险

| 风险 | 缓解 |
| --- | --- |
| 用户误以为 “EP” 只是序号 | 集头保留标题/子行标题，不做纯数字列表 |
| 半选态误判 | 半选不计入已选，点击集头补齐全选 |
| 大量单元导致长列表 | 固定高度滚动，不改变页面结构 |
| 不可下载行被忽略 | 原因常驻行尾，不只 hover |

## 不做

- 不新增搜索/筛选/排序、不新增“整季一键”。
- 不新增弹窗、抽屉或新路由。
- 不改变下载设置区结构。

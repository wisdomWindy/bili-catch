# 请求：模型管理按系列分组

## 目标

在模型管理弹窗中按模型系列展示模型，同一系列的模型位于同一分组。

## Done Signal

- Whisper 系列包含 Tiny、Base、Small、Medium 和 Large v3。
- FireRedASR2 系列包含 FireRedASR2 CTC INT8。
- 空分组不显示，各模型原有操作和状态保持不变。
- 分组标题支持中英文，组结构可被辅助技术识别。

## 触发与上下文

- 触发：用户打开“音频转文本”页的“模型管理”弹窗。
- 来源：用户直接指令；现有 `ModelManager.vue`、模型 ID 合同和本地化文案。
- 交接：完成自动化测试、类型检查、生产构建和弹窗视觉验证后交付。

## 路由与范围

- 直接变更，不需要 PRD 需求分析或模块拆分。
- 属于 `S1 local`：单个已有组件的局部信息架构调整，无 API 或状态合同变更。
- 需要 page-design；不需要 architecture-design，分组规则由组件内部纯派生逻辑所有。

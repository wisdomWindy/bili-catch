# 需求快照

## 来源摘要

用户要求应用启动时自动检查新版本，并在发现新版本时弹出确认更新弹窗。用户确认“立即更新”应直接下载安装，完成后自动重启应用。

## 关键业务目标

- 把已有的手动更新能力扩展到启动时自动触发。
- 仅在确有新版时打扰用户。
- 安装必须由用户明确确认。

## 显式行为约束

- 读取并尊重已有 `autoCheckUpdates` 设置。
- 等待设置成功加载后再决定是否检查，避免用默认值覆盖用户选择。
- 每次根组件生命周期最多自动检查一次。
- “已是最新”和检查失败均静默，不显示确认弹窗。
- 新版可用时显示当前版本和目标版本。
- 弹窗提供“稍后”和“立即更新”两个明确操作。
- 安装进行中禁止遮罩、Escape 和按钮关闭，防止安装状态与界面脱节。
- 安装失败后保留弹窗、展示错误并允许重试。
- 安装成功后沿用更新服务现有的自动重启行为。
- 设置页手动检查、安装按钮和托盘检查流程不回归。

## 表单、表格、展示与交互

- 表单：无新增表单；复用系统设置中的“自动检查更新”开关。
- 表格：不适用。
- 展示：全局模态弹窗展示标题、说明、当前版本、新版本及错误信息。
- 交互：“稍后”关闭；“立即更新”触发安装；安装失败后按钮恢复可用并可重试。

## 流程与状态规则

1. 根组件挂载并启动设置初始化。
2. 设置进入 ready 后读取 `autoCheckUpdates`。
3. 关闭时结束；开启时自动检查一次。
4. `latest` 或异常时静默结束。
5. `available` 时进入确认态并显示弹窗。
6. 用户稍后处理则关闭；用户确认则进入 installing。
7. 安装失败进入 error，显示错误且允许重试；成功后更新服务重启应用。

## 相关模块或页面

- 根应用容器 `src/app/App.vue`
- 更新服务 `src/features/settings/release.ts`
- 设置状态 `src/features/settings/store.ts`
- 新增全局确认弹窗组件
- 中英文 locale

## 开放问题

无。交互和错误处理已由用户确认的设计固定。

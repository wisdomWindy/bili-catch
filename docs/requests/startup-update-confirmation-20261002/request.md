# 启动时自动检查更新并确认安装

## 请求标识

`startup-update-confirmation-20261002`

## 来源

- 来源类型：用户直接需求与 2026-10-02 对话确认。
- 原始要求：应用启动时自动检查新版本，并在发现新版时弹出确认更新弹窗。
- 已确认决策：点击“立即更新”后直接下载安装，完成后自动重启应用。

## 业务摘要

复用现有 Tauri 更新器、手动检查更新功能和 `autoCheckUpdates` 设置，在应用启动完成设置加载后自动检查一次。发现新版本时以全局模态弹窗让用户选择稍后处理或立即更新。

## 目标

启用自动检查更新时，用户无需进入设置页即可获知新版并安全确认安装；没有新版或检查失败时不打扰正常启动。

## 初始完成信号

- 自动检查只在设置加载成功且 `autoCheckUpdates=true` 时执行一次。
- 新版可用时在当前页面显示确认弹窗，包含当前版本、新版本、“稍后”和“立即更新”。
- 安装期间禁用关闭，成功后由现有发布服务自动重启；失败时展示错误并允许重试。
- 已是最新版或自动检查失败时不弹窗；手动检查与托盘检查流程保持可用。
- 自动化测试、类型检查和构建门禁通过。

## 触发条件

应用根组件挂载并完成设置初始化后，且用户设置允许自动检查更新。

## 上下文来源

- 用户已批准的对话设计。
- `src/app/App.vue` 根生命周期。
- `src/features/settings/release.ts` 更新检查与安装端口。
- `src/features/settings/store.ts` 设置初始化状态。
- 现有 Naive UI 模态框与双语文案模式。

## 人工交接点

实现完成后交付代码、测试结果与构建验证；发布后由用户以可用新版清单进行一次桌面端冒烟验证。

## 影响范围

应用启动生命周期、发布操作注入、全局更新确认弹窗、国际化文案和相关前端测试。

## 业务摘要

为 BiliCatch 增加完全本地的音频转文本能力。用户可从本地音视频文件或已完成下载任务创建转写任务，按需管理 ASR 模型，查看转写进度，编辑结果并导出 TXT、SRT、VTT、JSON 或 Markdown。下载任务可配置完成后自动转写，转写任务在现有任务页统一呈现。

## 目标

在不破坏现有下载状态机和下载执行器的前提下，交付可实际运行的本地 ASR 子系统，包括 `/transcribe` 页面、模型管理、转写队列、FFmpeg 预处理、`whisper.cpp` sidecar 推理、多格式导出、设置扩展、任务页集成、下载后自动转写及错误码 E011-E017。

## 初始完成信号

1. 用户可选择或拖入 PRD 支持的音视频文件，选择已安装模型后创建转写任务。
2. 未安装模型可按需下载、校验、删除；模型下载和转写均有可观察进度与失败状态。
3. 转写链路完成 FFmpeg 16kHz 单声道 PCM 预处理、本地 sidecar 推理、分段结果解析、结果保存和临时文件清理。
4. TXT、SRT、VTT、JSON、Markdown 导出满足时间戳及命名规则，结果可编辑、复制和重新转写。
5. 转写任务可取消、失败重试、缓存复用，并在任务页与下载任务统一展示。
6. 设置页包含 PRD 列出的全部转写设置；音频/含音频下载支持完成后自动转写。
7. Rust 测试、前端测试、类型检查和构建通过；Windows 上完成真实 sidecar 与至少一个官方模型的烟测。
8. macOS/Linux 的 sidecar 定位和打包命名有契约测试，但平台二进制实机验证属于对应平台发布环境的交接项。

# `audio-transcription` 页面设计

## 交付单元标识

`audio-transcription`

## 页面目标

让用户在一个连续工作区内完成来源选择、模型/参数确认、任务观察和结果处理。页面优先支持经常性操作和状态扫描，不采用说明型首页、营销式 hero 或装饰性卡片堆叠。

## 目标用户与场景

- 学习者：把课程音视频转成可搜索文本、SRT 或 Markdown。
- 创作者：从已下载素材生成字幕草稿并进行文本级修订。
- 归档用户：批量管理本地模型和转写任务，导出结构化 JSON/VTT。
- 首次使用：尚未安装模型，需要从页面直接进入模型管理。
- 重复使用：从完成任务或本地文件快速开始，复用默认设置和缓存。

## 布局结构

### 应用壳

- 继续使用现有侧栏和顶部栏。
- 侧栏在“任务列表”和“设置”之间新增“音频转文本”，使用 Lucide `FileAudio` 或语义等价图标。
- 路由为 `/transcribe`，页面标题与侧栏文案来自 i18n。

### 主页面

页面内容宽度使用现有主内容区，不再套一层浮动卡片。纵向分为四个由分隔线组织的区块：

1. 页面标题栏：标题、紧凑状态摘要、模型管理图标按钮。
2. 来源区：已完成任务选择、本地文件按钮、拖拽区和文件信息。
3. 参数与运行区：模型/语言/格式/开关/目录及开始或取消命令。
4. 结果区：阶段进度、分段编辑器和结果操作工具栏。

桌面宽度下，来源与参数区使用两列网格：左侧约 40% 放来源和文件信息，右侧约 60% 放参数与目录。结果区始终占满内容宽度，保证长文本可读。

### 来源区

- 顶部为来源模式分段控件：“已完成任务”“本地文件”。
- 任务模式显示可搜索下拉；条目显示文件名、任务类型和完成时间，失效输出禁用并标识原因。
- 本地模式显示文件路径输入（只读）和文件选择图标按钮。
- 拖拽区是来源区的一部分，不再放入第二层卡片；空态使用文件音频图标和短文案。
- 有效来源后，拖拽区替换为文件信息列表：文件名、时长、大小、格式、完整路径（省略显示、tooltip 展示完整值）。

### 参数与运行区

- 第一行：模型、语言、输出格式三个等宽下拉。
- 模型字段旁使用下载/管理图标按钮，tooltip 说明“管理模型”。
- 第二行：时间戳、标点恢复、自动复制三个复选框/开关。
- 时间戳在 SRT/VTT/JSON 下保持勾选和禁用，并显示简短原因；TXT/Markdown 可编辑。
- 第三行：保存目录输入和目录选择图标按钮。
- 底部命令条右对齐：主按钮“开始转写”；运行时替换为危险语义较弱的“取消”按钮和当前阶段文本。

### 进度与结果区

- 创建任务后立即显示固定高度进度行，避免动态内容导致布局跳动。
- 进度行包含阶段、进度条、百分比、已处理/总时长、速度和 ETA；窄屏分两行。
- 结果为空时不展示大型说明卡，只显示与当前状态对应的简洁空态。
- 完成后展示分段列表。每行固定时间戳列和自适应文本编辑区；时间戳只读，文本可编辑。
- 结果工具栏使用熟悉图标配文字：复制全文、复制带时间戳、导出、打开目录、重新转写。
- 导出格式仍由参数区控制；导出按钮不再弹出重复格式选择。

### 模型管理弹窗

- 使用单层、最大宽度约 760px 的模态框。
- 顶部标题、模型目录摘要和关闭图标。
- 主体为扁平列表而非卡片网格；列为模型、体积/用途、状态、操作。
- 每行可显示下载进度条。已安装模型提供“设为默认”“校验”“删除”；默认模型用轻量标签表示。
- 删除使用中模型触发二次确认对话框；确认框不嵌套在模型弹窗 DOM 视觉容器内。
- 下载失败在对应行内显示错误和重试，不能只使用全局 toast。

## 视觉层级

1. 页面标题：沿用设置页 24px 标题尺度。
2. 区块标题：16px、600-650 字重，附 12-13px 次要状态。
3. 表单标签和任务元信息：12px muted；正文与可编辑文本：14px。
4. 主命令只保留一个品牌色按钮；其余使用 quiet/secondary 样式。
5. 错误、警告、成功和信息沿用现有红、橙、绿、蓝语义色，不新增单色主题。
6. 容器圆角不超过 8px；输入和按钮沿用 6px。

## 区块明细

| 区块 | 初始态 | Loading/运行态 | 错误态 | 成功态 |
| --- | --- | --- | --- | --- |
| 来源 | 任务/文件选择与拖拽 | 读取元信息时禁用来源切换 | 行内显示文件错误，可重新选择 | 文件信息可扫描 |
| 模型 | 当前默认模型 | 列表/下载显示 skeleton 或进度 | 模型行显示 E012/E017 | 显示已安装/默认状态 |
| 创建 | 按钮按前置条件禁用 | 防重复提交 | 页面级错误条，保留输入 | 显示任务进度 |
| 转写 | 无结果空态 | 阶段进度与取消 | 错误详情、重试/更换模型 | 分段编辑和工具栏 |
| 导出 | 禁用 | 按钮 pending | E016 行内反馈 | 显示已保存路径并可打开目录 |

## 样式方向

- 复用 `tokens.css` 颜色、现有表单高度、按钮、分隔线和焦点环。
- 新增 `transcription.css` 仅描述当前页面和模型弹窗；共享按钮优先复用 `AppIconButton` 或既有命令按钮样式。
- 页面区块使用全宽分隔带，不把每个区块做成浮动卡片，也不出现卡片嵌套。
- 进度数值使用 tabular numerals，避免变化时列宽抖动。
- 文本编辑区采用稳定最小高度和可滚动区域；长单词/路径允许换行或省略，不越界。
- 拖拽 active 状态使用边框和浅色背景变化，不使用装饰渐变或光斑。

## 交互骨架

1. 路由 query 有 `taskId` 时优先加载对应完成任务；无效时保留页面并显示可恢复错误。
2. 用户切换来源或选择新文件时清除尚未提交的旧文件元信息，但不删除已完成结果。
3. 模型未安装时模型字段显示缺失状态；点击开始不会静默下载，而是聚焦模型管理并给出 E011。
4. 创建成功后锁定本次任务参数；页面表单可展示任务参数，但重新转写前才重新启用编辑。
5. 离开页面不取消后台任务；返回后从快照和事件恢复。
6. 取消需确认清理中的短暂 pending，完成后保留源和参数供重试。
7. 编辑结果后导出使用当前编辑值；重新转写前若有未导出修改，弹出确认。
8. 复制成功通过短暂状态反馈；复制失败显示可访问错误，不改变任务状态。

## 相关页面增量

### 任务页

- 筛选扩展为“全部/下载/转写/进行中/已完成/失败”，在可用宽度不足时允许横向滚动，不挤压文字。
- 文件列增加紧凑类型标识；转写任务的速度列显示实时倍率，大小列替换为已处理/总时长。
- 已完成下载任务菜单增加“转写”；转写完成任务菜单提供“查看结果/打开目录”。
- 行组件接收统一展示模型，但下载/转写动作仍分派到各自服务。

### 设置页

- 在下载设置和外观设置之间插入“转写设置”。
- 使用既有 `SettingSection`/`SettingRow`、下拉、开关、范围和路径控件。
- 模型下载源为单行文本；blur 或 Enter 提交，保存前 trim，错误留在字段行。

### 下载中心

- 在音频或视频+音频模式的选项区增加单个“下载完成后自动转写”复选框。
- 仅视频模式隐藏该选项；全局默认开启时初始勾选，用户可按任务覆盖。

## 响应式行为

- `>= 940px`：来源/参数两列，结果全宽。
- `680-939px`：来源和参数改为单列；参数字段保持两列后按空间折行。
- `< 680px`：全部单列，命令条按钮占满可用宽度；结果工具栏允许换行；分段行改为时间戳在上、文本在下。
- 模型弹窗在窄屏占 `calc(100vw - 24px)`，列表转换为每行两段式信息，不发生横向溢出。
- 任务表继续使用现有 container query；新增类型和转写指标不得破坏 777px 以下两列布局。

## 可访问性

- 所有图标按钮具备 tooltip 与可访问名称。
- 来源分段控件、任务筛选使用正确的选中状态；进度使用 `progressbar` 语义和文本备份。
- 拖拽区同时可通过键盘触发文件选择，不依赖拖拽。
- 状态不只依靠颜色；错误、阶段和安装状态均显示文本/图标。
- 模态框打开后聚焦标题或首个可操作项，关闭后恢复触发按钮焦点。

## 设计风险

- 结果编辑器可能随长音频生成大量分段；需要虚拟化或分页阈值，但首版应先以可测试的分段列表和滚动容器实现，不提前引入重型编辑器。
- 任务筛选数量增加可能挤压窄屏；通过横向滚动和短标签控制。
- 模型下载进度与转写进度同时出现时不能共用一个全局 busy 状态。
- 页面重入需要区分正在运行任务、完成结果和尚未提交表单，避免一个 store 状态覆盖全部场景。

## 未决 UI 问题

没有阻塞性 UI 问题。分段数达到性能阈值时是否启用虚拟列表由实现期基准决定，但 DOM 数量和滚动性能必须纳入验证。

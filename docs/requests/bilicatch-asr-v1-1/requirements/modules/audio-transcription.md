# 模块：本地音频转文本与集成

## 模块标识

`audio-transcription`

## 模块名称

本地音频转文本、模型管理、结果导出及下载/任务/设置集成。

## 来源快照

以下内容保持 `biliCatch_PRD.md` 模块八及跨模块补充的原始业务语义：

### 功能与输入输出

- 从已下载的音频/视频文件或本地媒体文件中提取语音，使用本地 ASR 生成文本与字幕。
- 支持 MP3、M4A、AAC、FLAC、WAV、OGG、MP4、MKV、FLV、MOV、WebM。
- 支持从已完成下载任务选择、系统文件选择器选择和拖拽媒体文件。
- 支持 TXT、SRT、VTT、JSON、Markdown；SRT/VTT/JSON 有时间戳，TXT 默认无，Markdown 可选。
- 支持 Tiny、Base、Small、Medium、Large-v3；默认 Base，模型按需下载，不内嵌安装包。

### 页面与操作

- `/transcribe` 展示来源、文件信息、模型、语言、输出格式、时间戳、标点、自动复制、保存目录和转写结果。
- 从任务选择时自动带入路径、标题、时长。
- 本地文件选择器过滤支持格式；拖拽自动填充并读取元信息。
- 模型管理支持下载、删除、校验和默认切换。
- 已选择源文件和模型时创建转写任务；等待或运行中可取消并清理临时 PCM。
- 结果可复制纯文本、复制带时间戳、导出、打开目录和重新转写。
- 结果允许文本级修改，不提供完整字幕时间轴编辑器。

### 主流程与异常

1. 校验文件存在性与格式。
2. FFmpeg 抽取音轨并重采样为 16kHz 单声道 PCM。
3. 检查模型；未安装引导下载，已安装加载模型。
4. 创建任务、排队、分配转写槽位。
5. whisper.cpp 推理，生成分段文本和时间戳。
6. 后处理并生成目标格式，保存后清理 PCM。
7. 发送系统通知。

异常映射：模型未安装 E011、模型下载失败 E012、音频解码失败 E013、转写失败 E014、无语音 E015、保存失败 E016、模型校验失败 E017。

### 任务与进度

- 转写任务在任务页展示并提供类型筛选。
- 状态机：`Pending -> Transcribing -> Processing -> Completed`，支持 `Cancelled`、`Error`、重试。
- `transcribe://progress` 包含 task_id、stage、progress、processed_seconds、total_seconds、speed、eta、message。
- `transcribe://model_download_progress` 提供模型下载进度。
- 默认转写并发 1，可配置 1-3；转写优先级低于下载。

### 业务规则

- 音频和文本不上传。
- 自动语言检测，也可选择简中、繁中、英语、日语、韩语。
- 有平台 CC 字幕且启用优先设置时先使用平台字幕，否则走 ASR。
- 输出名 `{源文件名}.{语言}.{扩展名}`，冲突追加编号。
- 相同文件/模型/语言/格式默认复用缓存；重新转写忽略缓存。
- 长音频分段并按静音对齐；完成或取消立即清理 PCM。
- 模型支持下载、删除、校验；删除使用中模型需二次确认。
- 模型下载源可配置，默认官方源。

### 设置与集成

- 默认模型 Base、默认语言自动、默认格式 SRT、时间戳开、标点开、平台字幕优先开、自动转写关、并发 1、模型目录 `~/.bilicatch/models/whisper`、GPU 自动、官方模型源。
- 下载中心允许音频/含音频任务选择完成后自动转写。
- 已完成下载任务提供“转写”，跳转 `/transcribe?taskId=...`。
- 转写完成/失败发送系统通知。

### 技术与分发

- ASR 使用 `whisper.cpp` sidecar，服务层抽象 `Transcriber`。
- FFmpeg 负责音频预处理。
- 模型下载后校验 SHA-256。
- IPC 建议：`create_transcribe_task`、`cancel_transcribe_task`、`list_asr_models`、`download_asr_model`、`delete_asr_model`、`get_transcript_result`、`export_transcript`。
- `bundle.externalBin` 增加 whisper；sidecar 随程序更新，模型目录随更新保留。
- Tiny/Base 4 核 CPU 目标不低于 2x 实时，Small 不低于 1x 实时；GPU 优先 CUDA/Metal/Vulkan。

## 业务意图

让学习者、创作者和归档用户在不上传媒体的前提下，把已下载或本地媒体转成可检索、可编辑、可复用的文本/字幕资产。

## 用户可见范围

- 新转写页面与侧栏入口。
- 模型管理与下载进度。
- 转写进度、结果预览编辑、复制和导出。
- 任务页转写任务与完成下载任务入口。
- 设置页转写分组。
- 下载中心自动转写选项。
- 完成/失败通知和本地隐私说明。

## 表单、列表、展示与交互

字段、默认值、操作和状态以 `artifacts/prd-snapshot.md` 对应表格为完整上游合同；下游不得缩减。任务页在同一列表中使用类型标识和筛选区分下载/转写，不在转写页面复制完整任务管理功能。

## 工作流与状态规则

- 创建前校验源文件和模型，创建成功后进入持久化队列。
- 调度遵守并发上限和下载优先级。
- 预处理、加载、推理、后处理、保存都有可观察阶段。
- 取消、失败、完成都是稳定终态；失败可重试，重新转写可绕过缓存。
- 模型下载和转写事件必须可与初始查询快照安全合并。

## 依赖与影响邻居

- 应用壳：路由、侧栏、标题和 i18n。
- 下载中心：自动转写选项及草稿字段。
- 下载任务：完成输出和完成事件。
- 任务页：联合投影、筛选和动作。
- 设置：schema 扩展、迁移、即时保存。
- 系统：通知、文件/目录选择、拖拽、打开目录。
- 发布：externalBin、平台二进制、模型目录保留。

# 请求：下载设置“下载完成后转写”行视觉优化

## 请求标识

`bilicatch-transcription-toggle-polish-20261114`

## 来源

- 用户直接指令（2026-11-14）：附下载中心截图，红框标注“下载完成后转写 / 使用当前转写预设生成本地文本”一行，指出“UI 样式不协调”，要求“修改使之变得更美观”。

## 业务摘要

下载设置区的自动转写开关目前没有专属样式：浏览器默认方形复选框、标题与说明挤在同一行、与上方两列下拉框没有对齐关系，视觉上像一段裸文本。需要在**不改变行为、文案与信息结构**的前提下，把它做成与现有设计系统一致的开关行。

## 目标陈述

让该行成为一个可点击的开关卡片：左侧开关、右侧两行文案（标题 + 说明），与下载设置区的间距、圆角、边框、品牌色保持一致。

## 初始完成信号

- 该行有明确容器（边框、圆角、内边距），不再是无样式裸文本。
- 开关为胶囊形，开启时使用品牌色，支持键盘焦点环。
- 标题与说明分行显示，说明为次要色。
- 行为、文案、显隐条件、可访问性语义不变。

## 触发条件

用户在下载中心解析成功后，下载设置区渲染自动转写选项。

## 上下文来源

- 截图（用户提供，1168×788）

- `src/features/download-center/download-center.css`

## 影响范围

- 仅 `download-center.css` 的该行样式；必要时补充 `DownloadOptions.vue` 的语义属性。
- 不改文案、不改 store、不改布局结构、不改其他控件。

## 参与模块

单一交付单元：下载中心「下载设置」区自动转写行。

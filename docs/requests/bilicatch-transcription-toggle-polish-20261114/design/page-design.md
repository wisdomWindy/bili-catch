# 页面设计：下载设置·自动转写开关行

## 目标与场景

用户解析成功后，在“下载设置”区决定是否在下载完成后自动转写。该行是本次唯一的视觉调整对象。

## 现状问题（来自截图与代码）

1. `input` 未去除原生外观，显示为 13px 方形复选框，与页面其他胶囊控件风格不一致。
2. `<strong>` 与 `<small>` 同行内联，标题与说明粘连成一句长文本（截图中“下载完成后转写使用当前转写预设生成本地文本”）。
3. 该行没有容器、没有内边距，与上方两列下拉框左右边缘不齐，视觉层级弱。
4. 开关与文案基线不齐，复选框偏上、文案偏下。

## 设计方案

做成一张与设置区同宽的“开关卡片”：

```
┌──────────────────────────────────────────────┐
│  ( ●)   下载完成后转写                        │
│         使用当前转写预设生成本地文本           │
└──────────────────────────────────────────────┘
```

- 容器：整行可点击，1px 边框、8px 圆角、12px/14px 内边距、浅灰底；与上方 `.option-grid` 间距 16px。
- 开关：38×22 胶囊轨道 + 18px 白色滑块，默认灰轨，开启为品牌色并右移；`transition 150ms`。
- 文案：标题 13px/600，说明 12px/1.45 次要色，两行垂直排列，间距 2px。
- 状态：hover 边框加深；focus-visible 2px 焦点环；checked 时边框与浅底带品牌色；无 disabled 态（该开关始终可操作）。

## 视觉层级与一致性

- 使用 `tokens.css` 变量（brand/border/text-muted/surface/surface-muted），自动适配深色主题。
- 圆角取 8px（卡片级），控件内部仍沿用 6px 体系；不引入新色值。
- 与 `.mode-selector` 的品牌浅底保持同一 `color-mix` 用法。

## 交互与反馈

- 点击卡片任意位置切换开关（原生 `label` 行为）。
- 键盘：Tab 聚焦、Space 切换；焦点环只在键盘聚焦时出现。
- 状态变化不仅靠颜色：滑块位置同时变化。

## 响应式

- 宽度 100%，窄屏下文案自动换行，不出现横向滚动。
- 与上方两列网格在 680px 以下变单列时仍保持 16px 间距。

## 可访问性

- 保留 `role="switch"` 与原生 checkbox 语义（`checked` 自动映射）。
- 焦点环对比度使用 `--color-focus`。
- 文案仍由 `<strong>`/`<small>` 表达主次，屏幕阅读器读序为“标题 + 说明”。

## 不做

- 不改文案、不加图标、不改显隐条件、不动其他控件与布局。

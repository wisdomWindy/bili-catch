# 任务页错误提示与进度订阅恢复

## 背景

0.3.1 下载《AI翻唱/SoVITS 4.1》合集第 2 集时，任务页顶部出现红色「发生未预期的错误」，但任务最终 100% 完成、文件可播放。

## 原因

- 任务页横幅只来自 `store.error`（任务操作/初始化失败）与 `store.eventError`（`download://progress` 订阅失败）。
- 后端对「任务不存在」「当前状态不允许该操作」使用 `AppError::internal`，前端把未细分错误统一显示为 `E_INTERNAL`。
- 事件订阅失败同样落到 `E_INTERNAL`，且没有重试/轮询兜底，界面进度会停住但后台下载继续。

## 改动

1. 新增错误码：`E019`（任务不存在或已删除）、`E020`（当前任务状态下无法执行该操作）、`E021`（进度连接失败，正在重试）。
2. Rust `control` 对不存在/非法状态返回 `E019`/`E020`，不再用 internal。
3. 前端事件订阅首次失败后重试 2 次（300ms、900ms）；成功后清除错误。
4. 三次均失败时显示 `E021`，并每 3 秒轮询 `list_download_tasks` 合并快照，进度继续更新；`dispose` 清理定时器。
5. 版本提升到 0.4.0，发布说明与 README 下载链接同步。

## 验收

- `E019`/`E020`/`E021` 中英文文案齐全。
- 订阅首次失败、二次成功时不保留错误。
- 订阅持续失败时显示 `E021`、启用轮询、dispose 后停止轮询。
- 既有任务页快照行为不回归。

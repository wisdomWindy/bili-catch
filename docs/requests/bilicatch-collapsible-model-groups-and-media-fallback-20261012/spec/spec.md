# 实现规格

## S1 模型系列折叠

- `group.models.length > 1` 时渲染系列标题按钮，默认 `aria-expanded=true`。
- 点击按钮以不可变方式切换该系列折叠状态；折叠时不渲染对应 `.model-series-list`。
- `group.models.length === 1` 时渲染静态标题和列表。
- 不改变系列分组映射、模型顺序、模型行操作或现有本地化文案。

## S2 媒体地址回退

- 候选顺序固定为 `primary_url`，随后为 `backup_urls` 的原顺序。
- `download_from_url` 返回 `E004`、`E005`、`E006` 或 `E009` 时保存该错误并尝试下一 URL。
- 其他错误立即返回，以保护本地 I/O、内部校验等非地址故障语义。
- `Paused`、`Cancelled`、`Completed` 均立即返回，不继续请求其他地址。
- 所有候选均发生地址级错误时返回最后一次错误；没有候选时返回既有 `E004`。

## 验收标准

1. 多模型 Whisper 系列可折叠/展开，单模型 FireRedASR2 系列没有折叠按钮。
2. 首选 URL 返回 404 后，备用 URL 成功时任务完成且两个 URL 都被请求。
3. 所有 URL 返回地址级错误时，每个 URL 均被请求，最后才返回错误。
4. 现有 412 回退、断点续传、暂停及媒体类型测试保持通过。

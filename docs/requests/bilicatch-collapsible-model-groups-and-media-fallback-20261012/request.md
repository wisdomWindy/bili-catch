# 请求：模型分组折叠与媒体地址回退

## 目标

1. 模型管理弹窗中，包含多个模型的系列可以展开或收起。
2. 媒体下载按首选地址、备用地址的既定顺序逐一尝试，仅在全部地址均不可用时返回下载错误。

## Done Signal

- 多模型系列默认展开，可通过系列标题按钮收起并再次展开。
- 单模型系列保持直接展示，不增加无效折叠操作。
- 折叠按钮支持键盘操作，并暴露 `aria-expanded` 与受控内容关系。
- 首选地址发生网络失败、鉴权/访问拒绝或客户端地址错误时继续备用地址。
- 暂停、取消及本地文件系统错误不被误当作地址失败重试。
- 所有候选地址失败后才返回最后一次地址错误。

## 来源与范围

- 来源：用户直接指令“模型分组做成可折叠的分组”及“首选地址不能下载就使用备用地址，所有地址都尝试之后且都不能正常使用才报错”。
- 触发：打开模型管理弹窗；或启动包含备用 URL 的媒体下载任务。
- 类型：直接变更，`S2 scoped`，涉及一个 Vue 组件及共享媒体字节下载器。
- 不需要 PRD 专用需求分析/拆分；不改变对外命令、持久化结构或模型清单。
- 不需要架构设计；沿用组件本地状态和现有候选 URL 循环。

## 交接

完成前必须通过前端组件测试、Rust 下载器回归测试、类型检查、构建及完整测试。

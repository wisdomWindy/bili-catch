# 直接变更快照

## 原文证据索引

- U1：“模型分组做成可折叠的分组，同一个分组中如果存在多个模型可以收起/展开”
- U2：“首选地址不能下载就使用备用地址，所有地址都尝试之后且都不能正常使用才报错”

## Closed-world 产品范围

| 条目 | 来源 | 规范化约束 |
| --- | --- | --- |
| 多模型分组折叠 | U1 | 仅模型数大于 1 的系列提供收起/展开；默认展开 |
| 单模型分组 | U1 | 保持直接展示，不提供多余折叠入口 |
| 地址尝试顺序 | U2 | 首选地址在前，备用地址按现有数组顺序在后 |
| 报错时机 | U2 | 地址级失败时继续；全部地址失败后才报错 |

## 代码事实（仅用于定位）

- `ModelManager.vue` 已按 `Whisper`、`FireRedASR2` 计算分组，但列表始终展开。
- `HttpByteDownloader::download` 已遍历首选及备用 URL，但当前只在错误码 `E009` 时继续。
- HTTP 401、403 与其他 4xx 分别映射为 `E005`、`E006`、`E004`，因此当前会提前退出。

## 禁止解释

- 不把“所有地址”扩大为无限重试或重复轮询同一地址。
- 不吞掉磁盘写入、检查点读取等本地错误。
- 不改变暂停/取消语义。
- 不新增系列管理、模型排序或下载源配置界面。

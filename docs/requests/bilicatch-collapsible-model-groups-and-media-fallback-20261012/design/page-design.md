# 页面交互设计

## 结构与视觉

- 保持现有模型管理弹窗、系列顺序和模型行布局。
- 多模型系列标题成为整行按钮：左侧系列名，右侧使用 Lucide `ChevronDown`。
- 收起时箭头旋转为向右，模型列表从布局中移除；展开时恢复。
- 单模型系列继续使用普通标题，避免出现没有实际价值的控件。

## 状态与可访问性

- 初始状态：所有系列展开。
- 状态 owner：`ModelManager.vue` 内部折叠集合，不改变 props/emits。
- 按钮使用原生 `button`，具备 `aria-expanded`、`aria-controls`；列表具有稳定 `id`。
- 焦点、hover 沿用项目颜色变量，标题字号保持紧凑；移动端不改变模型行断点。

## 组件边界

折叠逻辑只服务当前组件且状态简单，不抽取新组件或 composable。下载、删除、取消等既有操作及状态反馈不变。

# 归一化缺陷快照

## 来源摘要

用户报告双轨视频任务在未操作取消时自动进入“已取消”；`BV1P2HQzbE61` 的本机任务记录和官方媒体响应已确认问题发生在双轨进度聚合阶段。

## 关键业务目标

- 双轨下载在媒体轨开始时间不同的情况下仍能稳定完成。
- 下载百分比对用户保持单调，不因总量从单轨扩展为双轨而回退。
- 保留过期执行尝试自动停止以及显式用户取消的现有语义。

## 显式行为约束

- 任务管理器继续拒绝百分比或已下载字节回退的进度快照。
- 视频进度聚合器必须在上报前将计算百分比钳制为不低于当前已展示百分比。
- 合法的进度总量扩展不得触发下载控制器的取消状态。
- 不修改任务模型、事件载荷和 IPC 契约。

## 从来源提取的接口、事件、数据模型与流程规则

- `ProgressSink::report` 接收单轨 `DownloadProgress`。
- `VideoProgressState` 合并视频与音频进度并产生 `ExecutionUpdate::Progress`。
- `TaskManager::apply_execution_update_at` 只接受单调百分比与单调已下载字节。
- `ExecutionReporterPort::report` 返回 `false` 时，进度回调会停止过期执行尝试。

## 相关服务或模块

视频执行器进度聚合、任务状态机进度校验、下载控制器与 Rust 回归测试。
